Estrutura técnica do projeto

Seis componentes integrados formam o sistema — cada um com uma função específica.

📡
API Oficial WhatsApp Business
Conta ativada via BSP homologado pela Meta. Permite botões interativos, templates, catálogo e alto volume de envios sem risco de ban.
● Essencial
🤖
Plataforma de Automação
Fluxos configurados visualmente — sem programação para ajustes futuros. Qualificação, catálogo, oferta e escalonamento.
● Oficial
🛍️
Catálogo de Produtos
Produtos com foto, descrição e preço. O cliente visualiza e escolhe direto no WhatsApp. Atualização simples pela plataforma.
● Essencial
💳
Integração de Pagamento
O bot envia o link de checkout (Hotmart, Kiwify, Stripe ou similar). Cliente finaliza com segurança fora do WhatsApp.
● Configurável
🗂️
CRM e Registro de Leads
Cada conversa gera um registro com nome, contato, interesse e etapa do funil. Relatório mensal de performance incluído.
● Incluso
👤
Atendimento Humano
Quando necessário, o bot transfere ao atendente com histórico completo. Fora do horário, conversa entra em fila.
● Configurável
⚠️
Por que API Oficial?
Ferramentas não-oficiais (Z-API, Evolution API etc.) conectam um celular físico ao sistema — qualquer atualização do WhatsApp pode derrubar tudo e o número pode ser banido para sempre. A API oficial homologada pela Meta é o único caminho seguro para negócios sérios.
